# ムースの声テスト（ななみ）

入力した日本語の文字を、Microsoft Edge の読み上げの声「ななみ」
（`ja-JP-NanamiNeural`）で音声にして聞くための、小さなテストページです。

- 画面で文字を入れて「声を聞く」を押すと、サーバー側で音声を作って返します
- 最初から、ムースからリュウへのあいさつ文が入っています
- 鍵（APIキー）は何も要りません

## 中身

```
index.html     画面（文字入力・ボタン・再生の受け口）
api/say.js     音声を作るサーバー側の処理（Vercelの関数）
package.json   使う部品（msedge-tts）の指定
vercel.json    関数の実行時間の上限（30秒）の指定
```

`api/say.js` は `GET /api/say?text=こんにちは` でも
`POST /api/say {"text":"こんにちは"}` でも受け付け、
成功すると `audio/mpeg` の音声を返します。
声の元に届かない時は、壊れた音声ではなく、
理由が分かるエラー（502と日本語の文）を返します。

## Vercelへの置き方

どちらかの方法で置けます。アカウントや鍵の追加設定は要りません。

### 方法1：リポジトリを取り込む

1. このフォルダを GitHub 等のリポジトリに入れる
2. Vercel の画面で「Add New → Project」から、そのリポジトリを取り込む
3. 設定は初期のままで「Deploy」を押す
   （土台の指定は「Other」のままで大丈夫です。`index.html` が画面、
   `api/` の中身がサーバー側の処理として自動で置かれます）

### 方法2：コマンドで置く

このフォルダの中で:

```
npm install
npx vercel
```

画面の案内に従うと、そのまま公開用のアドレスが発行されます。

## 注意

- Edge の読み上げは、Microsoft が公式に公開している開発者向けの
  仕組みではありません。ブラウザの読み上げ機能が使っている窓口を
  借りている形なので、向こうの都合で予告なく止まったり、
  仕様が変わったりすることがあります。
- 一度に読み上げられるのは300文字までです。
- 音声はサーバー側で作るので、置く場所（Vercel）から
  Microsoft の声の元（speech.platform.bing.com）へ
  届く回線が必要です。
